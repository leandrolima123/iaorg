# Código de Conduta

O IAORG adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/) como código de conduta para todos os espaços do projeto: issues, Pull Requests, discussões e qualquer canal em que alguém represente o projeto.

## Em resumo

- **Respeito:** trate todo mundo com respeito, qualquer que seja a experiência, a origem ou a identidade da pessoa.
- **Crítica:** critique ideias e código, nunca pessoas. Aceite críticas construtivas.
- **Proibido:** assédio, ataques pessoais, linguagem ou imagens sexualizadas e expor dados privados de alguém.
- **Pessoas novas:** ajude quem está chegando.

## Como reportar

Se você presenciar ou sofrer um comportamento inaceitável, avise os mantenedores pelo reporte privado do GitHub (aba **Security** → **Report a vulnerability**, informando que é uma questão de conduta) ou por mensagem direta ao mantenedor no GitHub. Todo relato é tratado com sigilo.

Os mantenedores podem remover comentários, commits e contribuições que violem este código e, se preciso, banir quem insistir no comportamento.
