Para quem é

Feito para quem quer colocar a IA para trabalhar. Com controle.

É para você se

  • tem um negócio, uma agência ou implanta IA para clientes;
  • quer agentes que atendem, produzem conteúdo e organizam o trabalho, e não só um chatbot;
  • quer aprovar o que sai para fora e saber quanto cada agente custa;
  • se sente à vontade para seguir um passo a passo no terminal.

Não é para você se

  • procura uma ferramenta pronta, sem nenhuma instalação;
  • espera que a IA decida preço, contratação ou estratégia por você;
  • não quer usar uma chave paga da API do Claude.

O que você precisa: um computador com Docker (o módulo 00 ensina a instalar no Windows, Mac ou Linux), uma chave da API do Claude com créditos e, para os casos práticos, as contas dos serviços que quiser conectar. O IAORG é gratuito e de código aberto.

Perguntas

Antes de comprar.

Como recebo o curso?

Assim que o pagamento é confirmado, o PDF chega no seu e-mail. Pix confirma na hora; cartão, em poucos minutos.

Preciso saber programar?

Não. Você precisa seguir um passo a passo para instalar com Docker (módulo 00) e copiar alguns comandos. Depois, tudo é feito pela tela do IAORG, escrevendo em português.

O IAORG é pago?

Não. O IAORG é de código aberto e gratuito. O custo de uso é o da API do Claude (e de serviços que você conectar), cobrado direto na sua conta. O curso ensina a manter esse custo baixo.

Funciona no Windows?

Sim, com o Docker Desktop e o WSL. O módulo 00 tem o passo a passo para Windows, Mac e Linux, com os problemas mais comuns e a solução.

E se eu não gostar?

Você tem 7 dias para pedir o reembolso, sem precisar explicar o motivo. Basta responder o e-mail de entrega.

O curso é atualizado?

A plataforma evolui, e o curso acompanha. A lógica ensinada (organograma, ficha, permissões, aprovação e oficina) é a base do produto.
