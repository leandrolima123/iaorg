Agentes com ficha

Instruções, procedimentos, exemplos, modelo e limite de gasto por agente. O histórico guarda cada versão.

Oficina de trabalho

Tarefas rodam em um ambiente isolado: o agente planeja, executa, testa e só então entrega.

Minha mesa

Tarefas, aprovações, entregas e perguntas dos agentes em uma lista só, também no Telegram.

Rotinas

Tarefas, reuniões e avisos que se repetem: todo dia, toda semana ou a cada algumas horas.

Funções: automação que não gasta IA

Um tipo de funcionário que roda no servidor, sem modelo de linguagem. Vigia dados o tempo todo e só chama um agente quando há algo para decidir.

Você no controle

A IA trabalha. Quem decide é você.

  • Aprovação antes de sairMensagens a clientes e ações sensíveis esperam o seu sim, conforme a ficha de cada agente.
  • Limite de gastoOrçamento por empresa e por tarefa. Quando o limite chega, o trabalho para e avisa.
  • Tudo registradoA página de atividade mostra o que cada agente e cada função fez, e quando.
  • Chaves guardadas cifradasAs credenciais das integrações ficam no servidor, cifradas, e não entram nas conversas dos agentes.

Código aberto

Rode na sua máquina. Ou leve para o Claude Code.

O IAORG é open source. Suba tudo com Docker no seu servidor, leia cada linha e contribua. Com o plugin, o Claude Code conversa com a sua empresa por MCP: contrata agentes, cria tarefas e acompanha a obra.

  • Licença MIT
  • Docker Compose
  • Servidor MCP próprio
  • Plugin para Claude Code
Ver no GitHub Ler o guia
1. Baixe o código
git clone https://github.com/leandrolima123/iaorg.git && cd iaorg
2. Configure os segredos (veja os comentários no arquivo)
cp .env.example .env
3. Suba o app, o login e a oficina
docker compose up -d --build
1. Adicione o marketplace do IAORG
claude plugin marketplace add leandrolima123/iaorg

/plugin install iaorg@iaorg
